# BTC Strategy Lab — подбор торговой стратегии под биткоин за 5 лет

Исследование: какие классические стратегии действительно работали на BTC за 5 лет,
и чем «красивая подгонка под график» отличается от честного результата «вслепую».

## 🌐 Live demo

**→ https://2themooon.github.io/btc-strategy-lab/**

Сайт работает 24/7: облачная рутина (GitHub Actions) **каждый час** обновляет живую
бумажную торговлю и публикует сайт на GitHub Pages — компьютер держать включённым не нужно.

## Как открыть сайт локально

Просто **дважды кликните `site/index.html`** — он работает офлайн, без сервера и без интернета
(данные вшиты в `site/data.js`, Chart.js лежит локально).

Либо запустите локальный сервер:
```
python -m http.server 8777 --directory site
```
и откройте http://localhost:8777

## Что внутри сайта

1. **График BTC за 5 лет** (с лог-шкалой).
2. **Лучшие стратегии** — отдельно для дейтрейдинга (часовые свечи) и среднесрока
   (дневные, ~сделка раз в 1–2 недели). Победители выбраны по честному тесту вне выборки.
3. **Подгонка vs Реальность** — главный график: коэффициент Шарпа при подгонке под весь
   график против результата walk-forward. Наглядно показывает оверфиттинг.
4. **Карта подгонки** — тепловая карта параметров кросса скользящих средних.
5. **Walk-forward по шагам** — как стратегия «накладывается» на график вслепую, шаг за шагом.
6. **Галерея всех стратегий** — математика каждой стратегии, идея простыми словами,
   плюсы/минусы и две колонки результата (подгонка / вслепую).
7. **Сводная таблица** (сортируемая) и **выводы**.

## Два способа проверки (ключевая идея)

- **Подгонка (in-sample).** Параметры подбираются по *всей* 5-летней истории и на ней же
  оцениваются. Мы как будто видим будущее. Красивые цифры — но обман.
- **Вслепую (walk-forward / out-of-sample).** На *прошлых* данных подбираем параметры, торгуем
  их на следующем, ещё *не виденном* куске, и так шаг за шагом. Это реальный результат.

Движок построен **без заглядывания в будущее**: решение о позиции принимается на закрытии бара
по данным только до этого момента, доход начисляется на следующем баре. Комиссия 0,1% за сделку.

## Главные результаты (вне выборки)

| | Лучшая стратегия | Доходность | Шарп | Макс. просадка |
|---|---|---|---|---|
| Среднесрок (дневные) | **MACD** (12/26/9) | +154% | 1.16 | −28% |
| Дейтрейдинг (часовые) | **Канал Дончиана** | +191% | 0.95 | — |
| Эталон Buy & Hold | купи и держи | +84% | 0.50 | −77% |

Выводы: трендовые стратегии устойчиво обыгрывают рынок по риску; стратегии «возврата к среднему»
красиво подгоняются, но теряют деньги вне выборки; большинство дейтрейдинг-стратегий съедаются
комиссиями; чем меньше параметров — тем надёжнее.

## Структура проекта

```
fetch_data.py     — загрузка 5 лет BTC/USDT с Binance (дневные + часовые) -> data/
engine.py         — индикаторы, движок бэктеста без lookahead, метрики, сделки
optimize.py       — подгонка (grid search) и walk-forward (вне выборки)
run_all.py        — главный прогон всех стратегий -> results.json
build_site.py     — results.json -> site/data.js
site/             — сайт (index.html, style.css, app.js, content.js, data.js, vendor/)
```

## Пересчитать всё с нуля

```
python fetch_data.py     # обновить данные (нужен интернет)
python run_all.py        # прогнать стратегии, пересобрать results.json
python build_site.py     # обновить site/data.js
```

## Живая рутина: бумажная торговля (📡 раздел на сайте)

Скрипт `paper_trade.py` ведёт живой форвард-тест трёх стратегий на BTC
(виртуальный капитал $10 000 на каждую) и пишет в `site/paper.js` открытые сделки,
журнал закрытых сделок и общий профит — раздел сайта **«Живая торговля»**:

- **Подгонка** — Моментум 30/0.10, дневные (чемпион при подгонке под весь график);
- **Вслепую** — MACD 12/26/9, дневные (честный walk-forward победитель);
- **Дейтрейдинг** — пробой канала Дончиана 48ч, часовые, **со стоп-лоссом 2.5×ATR(24)**;
- плюс эталон Buy & Hold.

Форвард-тест стартует **с сегодняшнего дня** (дата фиксируется при первом запуске).
Вход/выход — по текущей цене при изменении сигнала; для Дончиана дополнительно
проверяется стоп-лосс по минимумам часовых баров. Логика проверена тестом `test_paper.py`.

> Это **симуляция (бумажная торговля)**, реальные ордера на бирже НЕ выставляются.

### Где крутится 24/7

Основной движок — **облако GitHub Actions** (`.github/workflows/paper.yml`): каждый час
запускает `paper_trade.py`, коммитит свежий `paper_state.json`/`paper.js` и публикует сайт
на GitHub Pages. Компьютер при этом может быть выключен. Источник данных —
`data-api.binance.vision` с резервом на Kraken (на случай гео-блокировок IP облака).

Локальная задача Планировщика Windows **`BTC_Paper_Trading`** (ежечасно) больше не нужна и
**отключена**, чтобы не было двух «писателей» в один файл. Включить обратно при необходимости:
`Enable-ScheduledTask -TaskName "BTC_Paper_Trading"`.

Управление задачей (PowerShell):
```powershell
Start-ScheduledTask   -TaskName "BTC_Paper_Trading"   # запустить сейчас
Get-ScheduledTaskInfo -TaskName "BTC_Paper_Trading"   # когда был последний запуск
Disable-ScheduledTask -TaskName "BTC_Paper_Trading"   # приостановить
Unregister-ScheduledTask -TaskName "BTC_Paper_Trading" -Confirm:$false  # удалить
```

Запустить вручную: `python paper_trade.py` · самотест логики: `python test_paper.py`
(лог — `paper_trade.log`, состояние — `paper_state.json`; чтобы начать заново,
удалите `paper_state.json`).
